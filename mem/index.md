# Project Memory

## Core
Mozok = premium CURATED learning platform (not open marketplace). Every course requires admin quality approval before publish.
Preserve Paper & Ink visual identity: off-white paper bg, deep ink fg, Poppins font, hand-drawn doodles, existing cards/spacing/nav. Do NOT redesign brand.
Product integrity: no fake social proof, no frontend-only entitlements, no progress from page opens, no certificate unless issued, no instructor self-approval, no browser-only security. All auth decisions server + RLS.
North-star = Weekly Mastery Learners (unique learners completing ≥1 server-verified mastery activity / 7d). Video watching is not mastery.
Every epic: plan first (data model, RLS, states, analytics, acceptance, tests, rollback) → approval → implement small forward-only changes → build+lint+typecheck+tests+security scan before claiming done.
